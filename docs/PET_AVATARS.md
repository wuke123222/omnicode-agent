# 本地虚拟偶像立绘

OmniCode 内置的 Lumi 与 Aster 是原创、由插件代码绘制的虚拟偶像。除此之外，用户可以在 **创意工坊 → 导入偶像立绘** 中选择自己拥有版权或已获授权使用的本地图片。

## 支持范围

- PNG 或 JPEG，真实格式必须与受支持解码器匹配；
- 源文件最大 8 MB；
- 宽高各为 32–2048 像素，总像素不超过 4,194,304；
- 首版为单张静态立绘、单个本地槽位；五种 Agent 状态由宿主动画和徽标表达；
- 不支持 GIF、SVG、Live2D、Lottie、音频、脚本、压缩角色包或远程 URL。

## 本地处理与删除

图片在后台解码到新的像素缓冲区，最长边缩至 512 像素后重新编码为 PNG。原始文件路径、EXIF/元数据、动画帧和附加字节不会保留。净化后的文件只保存在 JetBrains IDE 配置目录的 `omnicode/workshop/custom-idol.png`，不会加入项目、发送给模型、MCP 或 OmniCode 服务器。

点击 **移除自定义** 可删除该规范化副本；原始图片不会被删除。导入失败时，上一份有效立绘保持不变。
